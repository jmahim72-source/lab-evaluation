# Student Registration System (PHP & MySQL)

A simple, beginner-friendly student registration system built with Core PHP, MySQL, and HTML.

## 📁 Files in this Project

- `index.html` — The student registration form.
- `register.php` — Processes form submission via POST and inserts student details into MySQL.
- `database.sql` — SQL script to set up the `college` database and `students` table.

## 🚀 How to Run Locally with XAMPP

1. **Copy Files**: Place this `PHP_Lab_Preparation` folder inside your XAMPP web root directory (`C:/xampp/htdocs/`).
2. **Start Services**: Open the XAMPP Control Panel and start **Apache** and **MySQL**.
3. **Database Setup**:
   - Open phpMyAdmin: `http://localhost/phpmyadmin/`
   - Import `database.sql` or create a database named `college` with the `students` table.
4. **Launch**:
   - Open your browser and go to: `http://localhost/PHP_Lab_Preparation/index.html`
